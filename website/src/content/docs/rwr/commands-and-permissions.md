---
title: Commands and permissions
description: Operate RWR, inspect state, and delegate access safely.
---
Use `/rwr status` before and after configuration changes, `/rwr reload` to apply supported changes, and `/rwr reset <world-id>` only after verifying the exact managed world. Grant status visibility more broadly than reset or reload authority, and keep destructive operations restricted to trusted operators.

The server command help is the authoritative list for the installed release. Add-on commands live in their own wikis.
