---
title: Configuration
description: Configure managed worlds, providers, schedules, warnings, and safe destinations.
---
Start with one disposable world. Give it a stable RWR ID, select the provider/world name, configure an evacuation destination outside that world, and verify it with `/rwr status` before adding a schedule.

Treat world folders, permanent survival worlds, and evacuation destinations as safety-critical identifiers. Keep a backup while changing providers or migrating configuration. For the complete field-by-field and migration reference, see [Operations & migration](../../reference/operations-and-migration/).
