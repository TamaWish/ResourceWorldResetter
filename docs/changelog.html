Version 5 is the current split-platform line. Versions 4.2.1 and earlier are retained here as historical legacy releases, not as current configuration guidance.

Current · v5.0.02026

Split-platform architecture

ResourceWorldResetter 5 replaces the universal legacy artifact with platform-native builds sharing one tested coordination core.

Added

  • Dedicated Spigot/Multiverse-Core and Paper-Folia/Worlds artifacts
  • Stable world IDs and provider-aware display names
  • Timezone schedules and whole-minute warnings
  • Persistent history and active-operation journaling
  • Admin and player teleport GUIs
  • Public pre-reset and post-reset events

Fixed and hardened

  • Paper and Folia scheduler-thread teleport deadlocks
  • Non-blocking Folia entity-region evacuation
  • Provider wording in Paper/Folia status and history
  • Spigot command, countdown, and server-log visibility
  • Asynchronous reset and GUI continuation paths
  • Independent post-regeneration verification

Migration required: v4 configuration is not loaded automatically. Start from a fresh config-version: 5 file.
