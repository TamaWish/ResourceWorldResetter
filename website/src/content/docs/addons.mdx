Add-ons are optional companion plugins. Each one works with either RWR platform build through the public API, so your main RWR setup stays the same.

<CardGrid>
  <LinkCard title="PlaceholderAPI wiki" href="./placeholderapi/" description="Show world state, reset phases, countdowns, and outcomes anywhere PlaceholderAPI is supported." />
  <LinkCard title="Discord Webhook wiki" href="./discord/" description="Deliver reset warnings and final outcomes to a Discord channel reliably." />
  <LinkCard title="Prometheus wiki" href="./prometheus/" description="Export RWR metrics and bring them into Prometheus and Grafana." />
  <LinkCard title="Public API wiki" href="./api/" description="Use snapshots and events to create your own RWR-aware plugin." />
</CardGrid>

> [!NOTE]
> Server owners do not install a separate API JAR. The matching RWR platform plugin supplies it at runtime.
