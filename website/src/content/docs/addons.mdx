## Compatibility

- Use one ResourceWorldResetter runtime: `ResourceWorldResetter` for Spigot/CraftBukkit, or `ResourceWorldResetter-Paper-Folia` for Paper/Purpur/Folia.
- Add-ons use `softdepend` because either runtime may be installed; they reconnect when the RWR API is available.
- API consumers must compile with `rwr-api` as `provided` or `compileOnly`; RWR provides the classes at runtime.

See [Integration development](./reference/development/) for service discovery and event-handling guidance.
