The public RWR API is a separate developer product. It lets plugins observe managed worlds and reset activity without depending on RWR internals or a world-provider implementation.

  <Card title="Service discovery" icon="magnifier">Find either RWR runtime safely through Bukkit services.</Card>
  <Card title="Snapshots" icon="document">Read immutable world and reset state.</Card>
  <Card title="Events" icon="notification">Observe warnings and outcomes or cancel a pre-reset event.</Card>
