title: API compatibility
description: Supported versions and compatibility expectations for RWR integrations.
---
import { Aside } from '@astrojs/starlight/components';

The supported public baseline is API 5.1.2 and ResourceWorldResetter 5.1 or newer. Compatibility is maintained throughout RWR 5.x. Minor releases may add methods, event types, or enum constants; include a default branch when switching over enums.
<Aside type="note">Maven Central version 5.1.1 was withdrawn because it contained an obsolete package. Use 5.1.2.</Aside>
Removals, package moves, and incompatible signatures are reserved for RWR 6.0.
